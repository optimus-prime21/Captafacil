¿Qué es CaptaFácil?

💧 Captación

Recolectamos agua de lluvia mediante canaletas de PVC y recipientes de gran capacidad, aprovechando un recurso gratuito que hoy se desperdicia.

🌱 Filtración natural

Filtramos con capas de grava, arena, carbón activado y geotextil. Sin químicos, sin energía eléctrica, sin complicaciones.

🏫 Enfoque comunitario

Diseñado para escuelas, centros deportivos y espacios comunitarios. El agua se usa para limpieza, lavado y riego.

💰 Bajo costo

Materiales locales y mano de obra capacitada. Hasta un 50% más económico que las alternativas comerciales.

Productos en venta

Soluciones naturales para limpiar y aprovechar el agua de lluvia en hogares, escuelas y comunidades. Diseñados con materiales accesibles, durables y de bajo mantenimiento.

Metodología POUR aplicada a este sitio

Este sitio fue diseñado siguiendo los cuatro principios de la accesibilidad web. Cada principio responde a cómo las personas con diferentes capacidades perciben, navegan y entienden la información.

👁️ Perceptible

La información se presenta en texto claro, con alto contraste y etiquetas ARIA para que los lectores de pantalla puedan describir cada elemento. Las imágenes decorativas usan aria-hidden.

⌨️ Operable

Todas las funciones se pueden usar con teclado. El menú se abre con Tab y Enter, y hay un enlace para saltar directamente al contenido principal.

🧠 Comprensible

El lenguaje es sencillo, sin tecnicismos innecesarios. La estructura del contenido es predecible y consistente. Cada sección tiene un encabezado claro.

🛡️ Robusto

El código usa HTML semántico válido y JavaScript no intrusivo. El sitio funciona correctamente en navegadores modernos y lectores de pantalla como NVDA, JAWS o VoiceOver.
